## Sobre mí

Soy **Donaldo Ibarra**, desarrollador Full Stack en formación con base en México. Me gusta construir aplicaciones completas: desde el modelo de datos y la capa de acceso a base de datos en **Java**, hasta interfaces web con **React**, **TypeScript** y **SCSS**.

Me formé en el programa de desarrollo web y backend de **EBAC (Escuela Británica de Artes Creativas y Tecnología)**, donde trabajé proyectos prácticos de frontend (maquetación responsiva, accesibilidad, consumo de APIs, SPA con React) y de backend (JDBC, JPA/Hibernate, MongoDB, Spring IoC, Maven y Gradle).

- Actualmente fortalezco mis conocimientos en **Spring Boot**, arquitectura en capas y bases de datos relacionales.
- Me interesa el desarrollo de APIs, la calidad del código y las buenas prácticas de documentación.
- Busco oportunidades para colaborar en proyectos reales y seguir creciendo como desarrollador.

## Experiencia

**Proyectos académicos y personales** (2025 - actualidad)

- Diseñé una **aplicación Java multimódulo con Gradle** (libros, autores, usuarios, biblioteca y excepciones) con plugins de convención propios y un `Dockerfile` para ejecutarla en contenedor.
- Implementé **operaciones CRUD completas con JDBC** sobre MySQL para usuarios, direcciones y teléfonos, usando una interfaz genérica `OperacionesCRUD<T>` y consultas parametrizadas.
- Construí una capa de persistencia con **JPA** y otra equivalente con **MongoDB** para comparar ambos enfoques de almacenamiento.
- Practiqué **inyección de dependencias con Spring** por setter, constructor y anotaciones, configurando beans por XML y por clases `@Configuration`.
- Desarrollé una **SPA en React + TypeScript** que consume la API de TheAudioDB, con rutas, un hook personalizado para peticiones y un tema global con styled-components.
- Maqueté sitios responsivos con **SCSS modular** (parciales y mixins de breakpoints): un catálogo de películas que consume la API de TMDB y una tienda en línea con carrito y menú lateral funcionales en JavaScript.
